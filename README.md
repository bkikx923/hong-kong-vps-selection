## “直连”要拆成三条去程和三条回程来看

国内访问香港，电信、联通、移动各自走自己的出口，谁也不管谁。所谓三网直连，是三家运营商的去程和回程都单独做了优化。

电信方向看是否走 CN2，CN2 里再分 GT 和 GIA，GIA 的优先级和稳定性更高。联通方向看 AS9929，移动方向看 CMIN2 或 CMI。一套齐备的三网优化，通常是电信去程 CN2、联通去程 9929、移动去程 CMIN2，回程三家都做大陆方向优化。丽萨主机那条三网精品线就是这个结构，1 核 1GB 起价 ¥88/月；DMIT 香港 Pro 的方案也是电信 CN2 GIA 双向加联通 AS9929 加移动 CMI，公开报价 $39.9/月买 1 核 1GB。

对照下来，很多标着“香港直连”的机器其实只优化了电信一条去程，联通和移动用户访问时按普通国际路由绕日本或新加坡，延迟直接翻倍。想验证也不难：找商家要测试 IP，用自己家里的宽带分别跑一次电信、联通、移动的 MTR，看每一跳落在哪个 AS 号上。三条路径都落在优化网段，才算真的三网直连。

LightLayer 的公开页面把线路统一描述为“针对中国大陆的特别优化线路”，带宽分成优化、全向、国际三档，没有逐条列出三网去回程的具体路由。买之前索取测试 IP 自己跑一遍，比看宣传页可靠。

## 带宽标的到底是端口、流量还是保证值

## 常见问题

**香港 VPS 需要备案吗？**
不需要。香港不在大陆备案管辖范围内，买完直接部署。

**到大陆的延迟到底多少？**
商家页面常写 5 到 22ms，那是实验室或最优路径下的数字。第三方实测普遍落在 30 到 55ms，晚高峰会往上走一点。同一个机房，电信、联通、移动三家用户的数字也不一样，以自己的宽带实测为准。

**晚高峰会不会掉速？**
主要看超售比例。物理机卖超了，晚高峰大家一起挤端口。挑商家时把“不超售”写进宣传的可以优先考虑，DMIT 就把这条当卖点。买之前问清楚单台物理机开多少实例。

**多久能开通？**
主流商家都是付款后自动开通，几分钟内收到 IP 和密码，LuckVM 写的是 1 到 5 分钟，网硕互联写最快 20 分钟交付。LightLayer 的具体交付时间在下单页确认。

**能装 Windows 吗？**
多数香港 VPS 支持，授权费另计。如果只是建站，Linux 加宝塔面板更省事，也不用付授权费。

**LightLayer 这家靠谱吗？**
它是 Megalayer 旗下的子品牌，2024 年成立，机房覆盖香港、台湾、日本、泰国、新加坡、菲律宾、美国、英国、德国，用 KVM 虚拟化和 AMD EPYC 平台。成立时间不长，长期稳定性还没有足够样本，这也是先买月付再考虑年付的理由。
